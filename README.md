# rugitg

Быстрый графический клиент Git в духе [gitg](https://gitlab.gnome.org/GNOME/gitg): тот же интерфейс и сценарии работы, но написан на Rust с интерфейсом на Tauri и не подвисает на больших репозиториях. Работает на Linux и Windows.

## Возможности

**Режим «История»**
- Список коммитов с графом веток. Цвета линий — из палитры Tango, как в gitg; длинные неактивные линии сворачиваются в стрелки.
- Боковая панель: все коммиты, текущая ветка, локальные ветки (с ↑/↓ относительно upstream), удалённые репозитории, теги, спрятанные изменения (stash). Выбор одной ссылки, нескольких (Ctrl+щелчок) или целого раздела фильтрует историю.
- Детали коммита: автор, коммиттер, SHA, родители (по ссылкам можно переходить), сообщение, список файлов со статистикой, дифф. Для слияний можно выбрать родителя для сравнения.
- Вкладка «Файлы»: дерево файлов коммита и просмотр содержимого (текст и изображения).
- Поиск (Ctrl+F) по заголовку, автору и SHA с переходом между совпадениями.
- Контекстные меню:
  - коммит: переключиться, создать ветку или тег, cherry-pick, revert, reset (soft/mixed/hard), создать патч, скопировать SHA;
  - ветка: переключиться, слить, pull, push, upstream, переименовать, удалить;
  - удалённая ветка: переключиться (с созданием отслеживающей ветки), слить, удалить на сервере;
  - удалённый репозиторий: fetch, изменить, удалить;
  - тег: переключиться, push, сведения, удалить;
  - stash: apply, pop, drop.
- Кнопки fetch, pull и push в заголовке окна.

**Режим «Коммит»**
- Списки «Конфликты», «Проиндексировано», «Не проиндексировано», «Неотслеживаемые» с множественным выбором. Списки виртуализированы: десятки тысяч файлов прокручиваются и индексируются за доли секунды.
- Двойной щелчок, Пробел или Enter индексирует файл или убирает его из индекса; Delete отменяет изменения.
- **Построчное индексирование**: щелчком или перетаскиванием выделяются строки, щелчок по заголовку блока выделяет весь блок. Выделенное можно проиндексировать, убрать из индекса или отменить.
- Диалог коммита: исправление предыдущего коммита (amend), Signed-off-by, подпись GPG, счётчик длины заголовка, пропуск хуков.
- Конфликты показываются с подсветкой маркеров; можно взять «нашу» или «их» версию, отметить файл разрешённым, прервать или продолжить слияние, cherry-pick, revert или rebase.
- Добавление файлов в `.gitignore`, stash.

**Прочее**
- Список репозиториев: недавние, открыть, клонировать (с прогрессом), создать.
- Светлая и тёмная темы (по системе или вручную), русский и английский интерфейс.
- Две раскладки: дифф под списком коммитов или справа от него.
- Окно ввода пароля и подтверждения ключа сервера для HTTPS и SSH.
- Автообновление при изменениях в `.git`, например после команд в терминале, и при возврате фокуса в окно.
- Поддержка частичных клонов (`--filter=blob:none`): недостающие объекты докачиваются автоматически.
- Открытие репозитория из командной строки: `rugitg /путь/к/репозиторию`.

## Почему быстро

- **История загружается в фоновом потоке** и передаётся в интерфейс порциями. Первые коммиты видны сразу, окно не блокируется.
- **Порядок коммитов берётся из commit-graph** (`.git/objects/info/commit-graph`) — файла, в котором git хранит родителей и даты всех коммитов. Сортировка не распаковывает ни одного коммита, а заголовки и авторы читаются только для видимых строк (остальные — в фоне, для поиска). Коммиты новее commit-graph дочитываются обычным способом.
- **commit-graph создаётся автоматически.** Если в репозитории больше 20 тыс. коммитов, а commit-graph нет или он сильно устарел, rugitg в фоне запускает `git commit-graph write --reachable --split` — то же, что делают `git gc` и `git maintenance`. Со следующего открытия история загружается через него.
- **Граф вычисляется на Rust** один раз при загрузке. Интерфейс запрашивает только видимые строки: список виртуализирован и одинаково быстро работает с сотней и с миллионом коммитов.
- **Дифф ограничен по размеру.** Огромные файлы и коммиты на тысячи файлов не загружаются целиком, их можно открыть по кнопке.
- **Не следим за всем рабочим каталогом**, только за `.git`. Поэтому `node_modules` и подобные каталоги не тормозят работу. Статус обновляется при возврате фокуса в окно или по F5.

Пример: репозиторий git.git (86 тыс. коммитов, все ветки):

| | первые строки | вся история |
|---|---|---|
| с commit-graph | 0,06 с | 0,12 с |
| без commit-graph (первое открытие) | 0,7 с | 1,0 с |

Поиск по всей истории занимает доли секунды.

## Архитектура

- `src-tauri/` — бэкенд на Rust:
  - `git/history.rs` — обход истории и раскладка графа (lanes) со сворачиванием неактивных линий, как в gitg;
  - `git/commit_graph.rs` — чтение файла commit-graph (включая цепочки split-графов);
  - `git/diff.rs` — диффы и сборка частичных патчей для построчного индексирования;
  - `git/repo.rs` — ссылки, статус, детали коммитов, деревья, blob-объекты;
  - `git/cli.rs` — запуск `git`;
  - `askpass.rs` — запросы паролей: rugitg сам служит программой `GIT_ASKPASS`/`SSH_ASKPASS` и передаёт запрос в основное окно через локальное соединение с одноразовым токеном.
- `src/` — интерфейс на TypeScript без фреймворков.

Чтение (история, диффы, статус) выполняется через **libgit2**: быстро и без запуска процессов. Изменения (commit, checkout, merge, fetch, push и т. д.) выполняет **установленный `git`**. Поэтому хуки, LFS-фильтры, хранилища паролей (credential helpers), GPG-подпись и настройки из `.gitconfig` работают так же, как в командной строке.

## Требования

- Установленный Git версии 2.26 или новее, доступный в `PATH`. На Windows подойдёт [Git for Windows](https://git-scm.com/download/win): его Git Credential Manager покажет окно входа для HTTPS.
- Если git или ssh нужно имя пользователя, пароль, пароль ключа SSH или подтверждение ключа сервера, rugitg показывает своё окно (через `GIT_ASKPASS`/`SSH_ASKPASS`). Чтобы не вводить пароль каждый раз, настройте хранилище паролей git или ssh-agent. Если `GIT_ASKPASS` или `SSH_ASKPASS` уже заданы в окружении, используются они.
- На Windows нужен WebView2. В Windows 10 и 11 он уже установлен, а установщик при необходимости скачает его сам.

## Сборка

Общее: [Rust](https://rustup.rs), Node.js 18+ и Tauri CLI (`cargo install tauri-cli --version "^2"`).

### Linux

```sh
# Debian/Ubuntu
sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev librsvg2-dev patchelf
# Fedora
sudo dnf install webkit2gtk4.1-devel gtk3-devel librsvg2-devel

npm install
cargo tauri build                     # пакеты в src-tauri/target/release/bundle/
cargo tauri build --bundles deb       # только .deb
```

### Windows

Нужны Visual Studio Build Tools (компонент «Разработка классических приложений на C++»), Rust (msvc) и Node.js.

```powershell
npm install
cargo tauri build                     # установщики .exe (NSIS) и .msi
```

### Разработка

```sh
npm install
cargo tauri dev
```

Тесты раскладки графа: `cd src-tauri && cargo test`.
Замер скорости загрузки истории:

```sh
RUGITG_BENCH_REPO=/путь/к/репо cargo test --release --lib bench_walk -- --ignored --nocapture
```

### CI

`.github/workflows/build.yml` собирает пакеты для Linux (deb, rpm, AppImage) и Windows (exe, msi) при пуше тега `v*` или при ручном запуске.

| Клавиши | Действие |
|---|---|
| Alt+H, Ctrl+1 | История |
| Alt+C, Ctrl+2 | Коммит |
| F5, Ctrl+R | Обновить |
| Ctrl+F | Поиск коммитов |
| Ctrl+Shift+F | Fetch из всех удалённых репозиториев |
| F9 | Показать или скрыть боковую панель |

| Пробел, Enter, двойной щелчок | Индексировать файл или убрать его из индекса |

| Ctrl+O | Открыть репозиторий |
| Ctrl+W, Alt+← | Закрыть репозиторий |
| Ctrl+, | Параметры |

## Отличия от gitg

- Нет плагинов и аватаров Gravatar.
- Есть то, чего нет в gitg: кнопки pull/push в заголовке, список stash в боковой панели, разрешение конфликтов «наша/их версия», поддержка частичных клонов.
